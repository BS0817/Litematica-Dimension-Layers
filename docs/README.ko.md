# Litematica Dimension Layers

Minecraft Java 26.3용 Fabric 클라이언트 애드온입니다. 여러 차원의 Litematica 스키메틱을 **.ldl** 한 파일에 저장하고, 접속한 차원의 레이어를 자동으로 표시합니다.

## 설치와 시작

Java 25, Fabric Loader 0.19.5 이상, Fabric API 0.165.2+26.3, Litematica 0.29.1, MaLiLib 0.30.2를 설치합니다. [GitHub Releases](https://github.com/BS0817/Litematica-Dimension-Layers/releases)에서 배포용 **litematica-dimension-layers-0.1.0+mc26.3.jar**를 프로필의 **mods** 폴더에 넣습니다.

Litematica 메인 메뉴에서 **차원 레이어**를 선택합니다. Minecraft 키 설정에서 **차원 레이어 열기**에 키를 지정할 수도 있습니다. 기본 키는 미지정입니다.

1. 새 프로젝트를 만든 뒤 **영역 추가**로 Litematica의 현재 선택 영역을 넣거나 **파일 가져오기**로 기존 파일을 넣습니다.
2. 차원을 바꿔 같은 방식으로 등록합니다. **배치 설정**에서 현재 월드의 위치, 회전, 반전을 편집합니다. 공유할 기본 위치는 **프로젝트 기본값**과 **기본값 X, Y, Z**에서 설정합니다.
3. **연결 그룹**에서 기준 차원과 포탈 X/Z를 저장합니다. 레이어 편집에서 그룹을 선택하고 **기준점 동기화**를 켭니다. 네더 변환은 X/Z에만 8:1을 적용하고 음수는 내림합니다. Y는 레이어의 기본 높이와 Y 보정으로 계산합니다.
4. 프로젝트를 저장합니다. **다른 이름으로**는 독립 사본을 만듭니다. 개별 **내보내기**는 원본 스키메틱과 같은 바이트를 새 파일에 씁니다.

## 저장 및 테스트

프로젝트는 공유용 설계와 스키메틱을 담습니다. 현재 월드의 개별 배치는 별도로 저장됩니다. 같은 프로젝트를 다른 월드에서 열면 공유용 기본 위치를 사용합니다. 자세한 사용법과 제한은 [사용 설명](usage.md)과 [호환성](compatibility.md), 실행 검증은 [테스트 보고서](testing.md)를 참조하세요.

JDK 25에서 **gradlew.bat build**를 실행하면 빌드와 자동 검증이 진행됩니다. 코드는 [LGPL-3.0-only](../LICENSE)로 공개합니다.
