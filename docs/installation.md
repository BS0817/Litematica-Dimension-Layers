# Installation

Use Java 25 and a Minecraft Java Edition 26.3 Fabric profile. Install Fabric Loader 0.19.5, [Fabric API](https://modrinth.com/mod/fabric-api) 0.165.2+26.3, [Litematica](https://modrinth.com/mod/litematica/version/0.29.1) 0.29.1 and [MaLiLib](https://modrinth.com/mod/malilib/version/0.30.2) 0.30.2. Download the [release JAR](https://github.com/BS0817/Litematica-Dimension-Layers/releases) named **litematica-dimension-layers-0.1.0+mc26.3.jar** in **mods**. A server does not need the add-on.

Open the Litematica main menu (normally **M**) and click **Dimension Layers**. To use a shortcut, set **Open Dimension Layers** in Minecraft's Controls. The key is unassigned initially.

Uninstall by removing only the add-on JAR. Your original schematics and the .ldl archives remain on disk. .ldl requires this add-on. Export layers as .litematic for use with ordinary Litematica.
