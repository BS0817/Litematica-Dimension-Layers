# Litematica Dimension Layers

Install **litematica-dimension-layers-0.1.0+mc26.3.jar** in the Fabric profile's **mods** folder. It targets Minecraft Java 26.3 and Java 25 with Fabric Loader 0.19.5, Fabric API 0.165.2+26.3, Litematica 0.29.1 and MaLiLib 0.30.2.

- Save multiple dimensions and exact .litematic bytes in a single .ldl project.
- Display the active dimension automatically and set independent origins, rotations and mirrors.
- Link Overworld and Nether origins with 8:1 conversion, offsets and locks.
- Open the add-on from the Litematica menu or assign a shortcut. English and Korean are included.

This version supports one open project, captures loaded client blocks without entities, and uses the address supplied by Minecraft for multiplayer world identity. See the repository's README, usage, compatibility, and testing documentation for details.
